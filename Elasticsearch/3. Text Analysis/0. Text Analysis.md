## How It Works - Step by Step

### 1. Testing Vietnamese Analyzers

```json
// Test standard Vietnamese analyzer
POST /ecommerce_vn/_analyze
{
  "analyzer": "vietnamese_standard",
  "text": "Laptop Dell XPS 15 của năm 2024 với hiệu năng cao"
}
```

**Result:**
```json
{
  "tokens": [
    {"token": "laptop"},
    {"token": "dell"},
    {"token": "xps"},
    {"token": "15"},
    // "của" removed (stopword)
    {"token": "năm"},
    {"token": "2024"},
    // "với" removed (stopword)
    {"token": "hiệu"},
    {"token": "năng"},
    {"token": "cao"}
  ]
}
```

### 2. Testing Autocomplete Index Analyzer

```json
POST /ecommerce_vn/_analyze
{
  "analyzer": "vietnamese_autocomplete_index",
  "text": "Điện thoại Samsung"
}
```

**Analysis Flow:**

```
Original Text: "Điện thoại Samsung"
         ↓
[Char Filter - vietnamese_normalize]
"Dien thoai Samsung"  // Đ → D
         ↓
[Tokenizer - standard]
["Dien", "thoai", "Samsung"]
         ↓
[Filter - vietnamese_lowercase]
["dien", "thoai", "samsung"]
         ↓
[Filter - vietnamese_synonym]
["dien", "thoai", "smartphone", "di", "dong", "mobile", "samsung"]
         ↓
[Filter - vietnamese_edge_ngram] (min=2, max=15)
[
  "di", "die", "dien",                    // from "dien"
  "th", "tho", "thoa", "thoai",          // from "thoai"
  "sm", "sma", "smar", "smart",          // from "smartphone"
  "smartphone",
  "di",                                   // from "di"
  "do", "don", "dong",                   // from "dong"
  "mo", "mob", "mobi", "mobil", "mobile", // from "mobile"
  "sa", "sam", "sams", "samsu", "samsun", "samsung"
]
```

### 3. Testing Autocomplete Search Analyzer

```json
POST /ecommerce_vn/_analyze
{
  "analyzer": "vietnamese_autocomplete_search",
  "text": "điện thoại"
}
```

**Result:**

**Note:** No n-grams at search time - only at index time!

### 5. Search Examples

#### Example 1: Autocomplete Search (Partial Match)

```json
GET /ecommerce_vn/_search
{
  "query": {
    "match": {
      "name": "lapt"
    }
  }
}
```

**How it works:**
- Query "lapt" → analyzed by `vietnamese_autocomplete_search` → ["lapt"]
- Index has tokens: ["la", "lap", "lapt", "lapto", "laptop", ...]
- Matches documents 1 and 3 (Dell XPS and MacBook)

#### Example 2: Synonym Search

```json
GET /ecommerce_vn/_search
{
  "query": {
    "match": {
      "name": "máy tính"
    }
  }
}
```

**How it works:**
```
Query: "máy tính"
       ↓
[vietnamese_autocomplete_search analyzer]
       ↓
Tokens: ["may", "tinh", "laptop", "notebook", "computer"]
       ↓
Matches: Documents with "laptop", "notebook", or "computer"
Result: Dell XPS (doc 1), MacBook (doc 3), iPad (doc 4 - "máy tính bảng")
```

#### Example 3: Multi-field Search

```json
GET /ecommerce_vn/_search
{
  "query": {
    "multi_match": {
      "query": "smartphone cao cấp",
      "fields": ["name^3", "desciption^2", "tags"],
      "type": "best_fields"
    }
  }
}
```

**How it works:**
- Query analyzed: ["smartphone", "dien", "thoai", "mobile", "cao", "cap"]
- `^3` boosts product name 3x
- `^2` boosts description 2x
- Finds Samsung phone (has "smartphone" and "cao cấp" in tags)

#### Example 4: Phrase Search with Stopwords

```json
GET /ecommerce_vn/_search
{
  "query": {
    "match_phrase": {
      "desciption": "hiệu năng cao"
    }
  }
}
```

**How it works:**
- "hiệu năng cao" → ["hieu", "nang", "cao"]
- Matches docs where these tokens appear in order
- Finds Dell XPS and Samsung phone

## Key Differences from English Analysis

| Aspect | English | Vietnamese |
|--------|---------|------------|
| **Character normalization** | Less critical | Important (đ, Đ, tones) |
| **Stopwords** | "the", "is", "at" | "của", "và", "các" |
| **Compound words** | Less common | Very common ("điện thoại", "máy tính") |
| **Synonyms** | Important | Critical for compound word variations |
| **Stemming** | Available | Limited support (custom required) |

## Why This Configuration Works

1. **Index-time n-grams**: Enable prefix matching for autocomplete
2. **Search-time no n-grams**: Prevent overly broad matches
3. **Synonym expansion**: Handle Vietnamese compound word variations
4. **Stopword removal**: Ignore common words that don't affect meaning
5. **Character normalization**: Handle different Vietnamese character representations
6. **Multi-fields**: Allow both analyzed and exact keyword matching

This setup provides fast, relevant search results for Vietnamese content with proper autocomplete functionality!
