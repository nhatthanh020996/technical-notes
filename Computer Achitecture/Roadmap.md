# Computer Architecture Learning Roadmap

## 1. Fundamentals
- **Digital Logic**
  - Binary Systems
  - Logic Gates (AND, OR, NOT, XOR)
  - Truth Tables
  - Combinational Circuits (Multiplexers, Decoders, Adders)
  - Sequential Circuits (Flip-Flops, Registers, Counters)
- **Number Systems**
  - Binary, Decimal, Hexadecimal
  - Number Conversion
  - Signed and Unsigned Numbers

## 2. Computer Organization
- **Basic Components**
  - CPU
  - Memory (Primary/Secondary)
  - I/O Devices
- **Instruction Set Architecture (ISA)**
  - RISC vs. CISC
  - Examples: ARM, x86
- **Data Representation**
  - Endianness (Big vs. Little)
  - Floating Point Representation (IEEE 754)

## 3. CPU Design
- **Datapath and Control**
  - Instruction Fetch, Decode, Execute
  - Single-Cycle vs. Multi-Cycle Execution
- **Pipelining**
  - Stages: Fetch, Decode, Execute, Memory Access, Write Back
  - Hazards: Structural, Data, Control
- **Advanced Features**
  - Superscalar Architecture
  - Out-of-Order Execution
  - Branch Prediction

## 4. Memory Hierarchy
- **Cache Memory**
  - Levels: L1, L2, L3
  - Mapping Techniques: Direct, Associative, Set-Associative
- **Main Memory**
  - DRAM vs. SRAM
  - Access Methods
- **Virtual Memory**
  - Paging
  - Segmentation
  - TLBs (Translation Lookaside Buffers)

## 5. Parallelism
- **Instruction-Level Parallelism**
  - Pipeline Parallelism
  - Speculative Execution
- **Thread-Level Parallelism**
  - Multicore Processors
  - Hyper-Threading
- **Data-Level Parallelism**
  - SIMD (Single Instruction Multiple Data)
  - GPUs for Parallel Processing

## 6. Input/Output Systems
- **Buses**
  - Bus Architecture and Protocols
- **Interrupts**
  - Types: Maskable, Non-Maskable
- **Direct Memory Access (DMA)**
  - Role in High-Speed I/O

## 7. Storage Hierarchy
- **Primary Storage**
  - Registers, Cache, Main Memory
- **Secondary Storage**
  - HDDs vs. SSDs
  - RAID Configurations
- **Tertiary Storage**
  - Backup Drives, Tape Drives

## 8. Performance Optimization
- **Metrics**
  - Clock Speed, CPI, MIPS, FLOPS
- **Optimization Techniques**
  - Compiler Optimizations
  - Hardware Prefetching
  - Power-Efficiency Techniques

## 9. Emerging Trends
- **Quantum Computing**
  - Basics of Qubits and Quantum Gates
- **Neuromorphic Computing**
  - Brain-Inspired Architectures
- **Security in Architecture**
  - Spectre and Meltdown Vulnerabilities
  - Secure Processor Design

## 10. Resources
- **Books**
  - "Computer Organization and Design" (Patterson & Hennessy)
  - "Computer Architecture: A Quantitative Approach" (Hennessy & Patterson)
- **Online Courses**
  - Coursera, edX, MIT OpenCourseWare
- **Practical Tools**
  - Simulators: Logisim, MARIE
  - Assembly Language Programming
