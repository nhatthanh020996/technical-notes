# Object
---

### **1. Create an Object**
```javascript
const user = {
  name: "John",
  age: 30,
  isAdmin: true,
  greet: () => {
    console.log(`Hello, my name is ${this.name}`); // `this` refers to the outer context, not the object
  }
};
console.log(user); // { name: "John", age: 30, isAdmin: true }
```

---

### **2. Access Properties**
```javascript
console.log(user.name); // "John"
console.log(user["age"]); // 30
```

---

### **3. Add or Update Properties**
```javascript
user.email = "john@example.com"; // Add a new property
user.age = 31; // Update an existing property
console.log(user); // { name: "John", age: 31, isAdmin: true, email: "john@example.com" }
```

---

### **4. Delete a Property**
```javascript
delete user.isAdmin;
console.log(user); // { name: "John", age: 31, email: "john@example.com" }
```

---

### **5. Check if a Property Exists**
```javascript
console.log("name" in user); // true
console.log("isAdmin" in user); // false
```

---

### **6. Iterate Over Properties**
```javascript
for (const key in user) {
  console.log(`${key}: ${user[key]}`);
}
// Output:
// name: John
// age: 31
// email: john@example.com
```

---

### **7. Get Keys, Values, and Entries**
```javascript
console.log(Object.keys(user)); // ["name", "age", "email"]
console.log(Object.values(user)); // ["John", 31, "john@example.com"]
console.log(Object.entries(user)); // [["name", "John"], ["age", 31], ["email", "john@example.com"]]
```

---

### **8. Merge Two Objects**
```javascript
const address = { city: "New York", country: "USA" };
const userWithAddress = { ...user, ...address };
console.log(userWithAddress);
// { name: "John", age: 31, email: "john@example.com", city: "New York", country: "USA" }
```

---

### **9. Clone an Object**
```javascript
const clonedUser = { ...user };
console.log(clonedUser); // { name: "John", age: 31, email: "john@example.com" }
```

---

### **10. Check if an Object is Empty**
```javascript
const emptyObject = {};
console.log(Object.keys(emptyObject).length === 0); // true
```

---

### Summary Table:

| **Operation**                | **JavaScript Code**                                   |
|-------------------------------|-----------------------------------------------------|
| Create an object             | `const obj = { key: value };`                        |
| Access properties            | `obj.key` or `obj["key"]`                           |
| Add/update properties        | `obj.newKey = value;`                               |
| Delete a property            | `delete obj.key;`                                   |
| Check if property exists     | `"key" in obj`                                      |
| Iterate over properties      | `for (const key in obj) { ... }`                    |
| Get keys, values, entries    | `Object.keys(obj)`, `Object.values(obj)`, `Object.entries(obj)` |
| Merge objects                | `{ ...obj1, ...obj2 }`                              |
| Clone an object              | `{ ...obj }`                                        |
| Check if object is empty     | `Object.keys(obj).length === 0`                     |
