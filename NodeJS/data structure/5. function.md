
---

### **1. Function Declaration**
- **Definition**: A named function that can be called anywhere in the code (hoisted).
- **Syntax**:
  ```javascript
  function greet(name) {
    return `Hello, ${name}!`;
  }

  console.log(greet("Alice")); // "Hello, Alice!"
  ```

---

### **2. Function Expression**
- **Definition**: A function assigned to a variable. Not hoisted.
- **Syntax**:
  ```javascript
  const greet = function(name) {
    return `Hello, ${name}!`;
  };

  console.log(greet("Bob")); // "Hello, Bob!"
  ```

---

### **3. Arrow Function**
- **Definition**: A shorter syntax for writing functions. Does not bind its own `this`.
- **Syntax**:
  ```javascript
  const greet = (name) => `Hello, ${name}!`;

  console.log(greet("Charlie")); // "Hello, Charlie!"
  ```

---

### **4. Anonymous Function**
- **Definition**: A function without a name, often used as a callback.
- **Syntax**:
  ```javascript
  setTimeout(function() {
    console.log("This is an anonymous function.");
  }, 1000);
  ```

---

### **5. Immediately Invoked Function Expression (IIFE)**
- **Definition**: A function that runs immediately after being defined.
- **Syntax**:
  ```javascript
  (function() {
    console.log("IIFE executed!");
  })();
  ```

---

### **6. Constructor Function**
- **Definition**: A function used to create objects. Typically starts with a capital letter.
- **Syntax**:
  ```javascript
  function Person(name, age) {
    this.name = name;
    this.age = age;
  }

  const person = new Person("Alice", 25);
  console.log(person.name); // "Alice"
  ```

---

### **7. Generator Function**
- **Definition**: A function that can pause execution and resume later using `yield`.
- **Syntax**:
  ```javascript
  function* generateNumbers() {
    yield 1;
    yield 2;
    yield 3;
  }

  const generator = generateNumbers();
  console.log(generator.next().value); // 1
  console.log(generator.next().value); // 2
  ```

---

### **8. Async Function**
- **Definition**: A function that works with asynchronous code using `async` and `await`.
- **Syntax**:
  ```javascript
  async function fetchData() {
    const response = await fetch("https://jsonplaceholder.typicode.com/posts/1");
    const data = await response.json();
    console.log(data);
  }

  fetchData();
  ```

---

### **9. Method in an Object**
- **Definition**: A function defined as a property of an object.
- **Syntax**:
  ```javascript
  const user = {
    name: "Alice",
    greet() {
      console.log(`Hello, ${this.name}!`);
    }
  };

  user.greet(); // "Hello, Alice!"
  ```

---

### **10. Class Method**
- **Definition**: A function defined inside a class.
- **Syntax**:
  ```javascript
  class User {
    constructor(name) {
      this.name = name;
    }

    greet() {
      console.log(`Hello, ${this.name}!`);
    }
  }

  const user = new User("Alice");
  user.greet(); // "Hello, Alice!"
  ```

---

### **11. Function Using `new Function`**
- **Definition**: Creates a function dynamically using the `Function` constructor.
- **Syntax**:
  ```javascript
  const add = new Function("a", "b", "return a + b");
  console.log(add(2, 3)); // 5
  ```

---

### Summary Table:

| **Function Type**            | **Description**                                                                 |
|-------------------------------|---------------------------------------------------------------------------------|
| **Function Declaration**      | Named function, hoisted.                                                       |
| **Function Expression**       | Function assigned to a variable, not hoisted.                                  |
| **Arrow Function**            | Shorter syntax, no `this` binding.                                             |
| **Anonymous Function**        | Function without a name, often used as a callback.                             |
| **IIFE**                      | Function that executes immediately after being defined.                        |
| **Constructor Function**      | Function used to create objects.                                               |
| **Generator Function**        | Function that can pause and resume execution using `yield`.                    |
| **Async Function**            | Function that handles asynchronous operations with `async` and `await`.        |
| **Method in Object**          | Function defined as a property of an object.                                   |
| **Class Method**              | Function defined inside a class.                                               |
| **`new Function`**            | Dynamically creates a function using the `Function` constructor.               |



```js
function Animal() {}
Animal.prototype.speak = function() {
  console.log("This animal makes a sound.");
};

function Dog() {}
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.speak = function() {
  console.log("The dog barks.");
};

const dog = new Dog();
dog.speak(); // "The dog barks."
```
