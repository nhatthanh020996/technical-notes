# Array

---

### **1. `pop` (Remove the last element)**
```javascript
const arr = [1, 2, 3];
const lastElement = arr.pop(); // Removes and returns the last element
console.log(arr); // [1, 2]
console.log(lastElement); // 3
```

---

### **2. `append` (Add an element to the end)**
```javascript
const arr = [1, 2, 3];
arr.push(4); // Adds 4 to the end
console.log(arr); // [1, 2, 3, 4]
```

---

### **3. `extend` (Add multiple elements to the end)**
```javascript
const arr = [1, 2, 3];
arr.push(...[4, 5, 6]); // Adds multiple elements
console.log(arr); // [1, 2, 3, 4, 5, 6]
```

---

### **4. `enumerate` (Get index and value)**
```javascript
const arr = ["a", "b", "c"];
arr.forEach((value, index) => {
  console.log(index, value); // Logs index and value
});
// Output:
// 0 "a"
// 1 "b"
// 2 "c"
```

---

### **5. `zip` (Combine two arrays element-wise)**
```javascript
const arr1 = [1, 2, 3];
const arr2 = ["a", "b", "c"];
const zipped = arr1.map((value, index) => [value, arr2[index]]);
console.log(zipped); // [[1, "a"], [2, "b"], [3, "c"]]
```

---

### **6. Concatenate Two Arrays**
```javascript
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];
const concatenated = arr1.concat(arr2); // Combines both arrays
console.log(concatenated); // [1, 2, 3, 4, 5, 6]
```

---

### **7. `len` (Get the length of the array)**
```javascript
const arr = [1, 2, 3];
console.log(arr.length); // 3
```

---

### **8. Check if Array is Empty**
```javascript
const arr = [];
console.log(arr.length === 0); // true
```

---

### **9. `array[:1]` (Slice the array)**
```javascript
const arr = [1, 2, 3];
const sliced = arr.slice(0, 1); // Slices from index 0 to 1 (exclusive)
console.log(sliced); // [1]
```

### **10. `List Comprehension` in javascript**

```javascript
const numbers = [1, 2, 3];
const squared = numbers.map(x => x ** 2);
console.log(squared); // [1, 4, 9]
```

```javascript
function square(x) {
  return x ** 2;
}

const numbers = [1, 2, 3, 4];
const squaredNumbers = numbers.map(square);

console.log(squaredNumbers); // [1, 4, 9, 16]
```
---

### **11. `reduce` (Aggregate values in the array)**
```javascript
const arr = [1, 2, 3, 4];
const sum = arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
console.log(sum); // 10
```

---

### **12. `filter` (Filter elements based on a condition)**
```javascript
const arr = [1, 2, 3, 4];
const evenNumbers = arr.filter(num => num % 2 === 0);
console.log(evenNumbers); // [2, 4]
```
