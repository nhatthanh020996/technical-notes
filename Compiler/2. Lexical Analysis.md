# Article 2: Lexical Analysis - Breaking Down Source Code

## The Role of the Lexer

The lexer (or scanner) is the first phase of a compiler, responsible for breaking the source text into meaningful tokens. It transforms a stream of characters into a stream of tokens, where each token represents a logical unit in the language.

**Example**: For the C statement `int count = 10;`, the lexer produces:
```
[KEYWORD: int] [IDENTIFIER: count] [OPERATOR: =] [NUMBER: 10] [PUNCTUATION: ;]
```

This seemingly simple transformation handles significant complexity:
- Discarding whitespace and comments
- Recognizing language constructs
- Handling multi-character tokens
- Tracking source positions for error reporting

## Lexical Analysis Techniques

### Regular Expressions

Most tokens can be described using regular expressions:

- Keywords: `int|float|if|else|while|for|return`
- Identifiers: `[a-zA-Z_][a-zA-Z0-9_]*`
- Numbers: `[0-9]+(\.[0-9]+)?([eE][+-]?[0-9]+)?`
- Operators: `[\+\-\*/=<>!&|%^]+`

### Finite Automata

Lexers implement finite automata (state machines) to recognize patterns efficiently:

**Example**: A state machine for recognizing numeric literals:

```
START → saw_digit → saw_digit → ...
        ↓
        saw_dot → saw_digit_after_dot → saw_digit_after_dot → ...
                                      ↓
                                      saw_e → saw_sign → saw_digit_after_e → ...
```

## Practical Implementation

Here's a more complete lexer implementation in Python:

```python
import re

# Token definitions
TOKEN_TYPES = [
    ('KEYWORD', r'(int|float|if|else|while|for|return)'),
    ('IDENTIFIER', r'[a-zA-Z_][a-zA-Z0-9_]*'),
    ('NUMBER', r'[0-9]+(\.[0-9]+)?([eE][+-]?[0-9]+)?'),
    ('OPERATOR', r'[\+\-\*/=<>!&|%^]+'),
    ('LPAREN', r'\('),
    ('RPAREN', r'\)'),
    ('LBRACE', r'\{'),
    ('RBRACE', r'\}'),
    ('SEMICOLON', r';'),
    ('COMMA', r','),
    ('WHITESPACE', r'\s+'),
    ('COMMENT', r'//.*|/\*[\s\S]*?\*/')
]

class Token:
    def __init__(self, type, value, line, column):
        self.type = type
        self.value = value
        self.line = line
        self.column = column
    
    def __repr__(self):
        return f"Token({self.type}, '{self.value}', line={self.line}, col={self.column})"

class Lexer:
    def __init__(self, source_code):
        self.source_code = source_code
        self.tokens = []
        # Compile regex patterns
        self.token_regex = '|'.join(f'(?P<{name}>{pattern})' for name, pattern in TOKEN_TYPES)
        self.regex = re.compile(self.token_regex)
        
    def tokenize(self):
        line_num = 1
        line_start = 0
        
        # Find all tokens in the source code
        for match in self.regex.finditer(self.source_code):
            # Which token type matched?
            token_type = match.lastgroup
            token_value = match.group()
            column = match.start() - line_start + 1
            
            # Skip whitespace and comments
            if token_type == 'WHITESPACE' or token_type == 'COMMENT':
                # Update line number and start position
                newlines = token_value.count('\n')
                if newlines > 0:
                    line_num += newlines
                    line_start = match.start() + token_value.rindex('\n') + 1
                continue
            
            # Create token and add to list
            token = Token(token_type, token_value, line_num, column)
            self.tokens.append(token)
            
            # Update line tracking for multi-line tokens
            newlines = token_value.count('\n')
            if newlines > 0:
                line_num += newlines
                line_start = match.start() + token_value.rindex('\n') + 1
        
        # Add EOF token
        self.tokens.append(Token('EOF', '', line_num, 0))
        return self.tokens

# Example usage
source = """
int factorial(int n) {
    // Calculate factorial
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
"""

lexer = Lexer(source)
tokens = lexer.tokenize()

# Print all tokens except EOF
for token in tokens[:-1]:
    print(token)
```

## Error Handling in Lexers

Robust lexers must handle invalid input gracefully:

```python
def tokenize_with_error_handling(source):
    position = 0
    line = 1
    column = 1
    tokens = []
    
    while position < len(source):
        # Try to match a token at the current position
        matched = False
        
        # Skip whitespace
        if source[position].isspace():
            if source[position] == '\n':
                line += 1
                column = 1
            else:
                column += 1
            position += 1
            continue
        
        # Try each pattern
        for token_type, pattern in TOKEN_PATTERNS:
            regex = re.compile(pattern)
            match = regex.match(source, position)
            
            if match:
                value = match.group(0)
                tokens.append(Token(token_type, value, line, column))
                position = match.end()
                column += len(value)
                matched = True
                break
        
        if not matched:
            # Report error with context
            context_start = max(0, position - 10)
            context_end = min(len(source), position + 10)
            context = source[context_start:position] + "→" + source[position] + "←" + source[position+1:context_end]
            
            error_msg = f"Lexical error at line {line}, column {column}: " \
                        f"Unexpected character '{source[position]}'\n" \
                        f"Context: ...{context}..."
            
            # Add error token and try to recover
            tokens.append(Token('ERROR', source[position], line, column))
            position += 1
            column += 1
    
    return tokens
```

### Hands-on Exercise: Building a Calculator Lexer

Let's implement a complete lexer for a calculator language:

```python
class CalcLexer:
    # Token types
    INTEGER = 'INTEGER'
    FLOAT = 'FLOAT'
    PLUS = 'PLUS'
    MINUS = 'MINUS'
    MULTIPLY = 'MULTIPLY'
    DIVIDE = 'DIVIDE'
    POWER = 'POWER'
    LPAREN = 'LPAREN'
    RPAREN = 'RPAREN'
    EOF = 'EOF'
    
    def __init__(self, text):
        self.text = text
        self.pos = 0
        self.current_char = self.text[self.pos] if len(self.text) > 0 else None
        self.line = 1
        self.column = 1
    
    def error(self):
        raise Exception(f'Invalid character at line {self.line}, column {self.column}: {self.current_char}')
    
    def advance(self):
        if self.current_char == '\n':
            self.line += 1
            self.column = 0
            
        self.pos += 1
        self.column += 1
        
        if self.pos < len(self.text):
            self.current_char = self.text[self.pos]
        else:
            self.current_char = None
    
    def skip_whitespace(self):
        while self.current_char and self.current_char.isspace():
            self.advance()
    
    def number(self):
        """Parse a number from the input"""
        result = ''
        while self.current_char and self.current_char.isdigit():
            result += self.current_char
            self.advance()
            
        # Check for decimal point
        if self.current_char == '.':
            result += self.current_char
            self.advance()
            
            # Must have at least one digit after decimal
            if not (self.current_char and self.current_char.isdigit()):
                self.error()
                
            while self.current_char and self.current_char.isdigit():
                result += self.current_char
                self.advance()
                
            return ('FLOAT', float(result))
        else:
            return ('INTEGER', int(result))
    
    def get_next_token(self):
        """Lexical analyzer"""
        while self.current_char:
            # Skip whitespace
            if self.current_char.isspace():
                self.skip_whitespace()
                continue
                
            # Numbers
            if self.current_char.isdigit():
                return self.number()
                
            # Operators
            if self.current_char == '+':
                self.advance()
                return ('PLUS', '+')
                
            if self.current_char == '-':
                self.advance()
                return ('MINUS', '-')
                
            if self.current_char == '*':
                self.advance()
                return ('MULTIPLY', '*')
                
            if self.current_char == '/':
                self.advance()
                return ('DIVIDE', '/')
                
            if self.current_char == '^':
                self.advance()
                return ('POWER', '^')
                
            # Parentheses
            if self.current_char == '(':
                self.advance()
                return ('LPAREN', '(')
                
            if self.current_char == ')':
                self.advance()
                return ('RPAREN', ')')
            
            # Unknown character
            self.error()
            
        return ('EOF', None)
    
    def tokenize(self):
        """Return all tokens in the input"""
        tokens = []
        token = self.get_next_token()
        
        while token[0] != self.EOF:
            tokens.append(token)
            token = self.get_next_token()
            
        tokens.append(token)  # Include EOF token
        return tokens

# Test the lexer
def test_lexer():
    test_cases = [
        "2 + 3 * 4",
        "7.5 / (3 - 2)",
        "2^3 + 4",
        "1.23 + 4.56"
    ]
    
    for test in test_cases:
        lexer = CalcLexer(test)
        tokens = lexer.tokenize()
        print(f"Input: {test}")
        print(f"Tokens: {tokens}")
        print()
        
test_lexer()
```

Output:
```

Tokens: [('INTEGER', 2), ('PLUS', '+'), ('INTEGER', 3), ('MULTIPLY', '*'), ('INTEGER', 4), ('EOF', None)]

Input: 7.5 / (3 - 2)
Tokens: [('FLOAT', 7.5), ('DIVIDE', '/'), ('LPAREN', '('), ('INTEGER', 3), ('MINUS', '-'), ('INTEGER', 2), ('RPAREN', ')'), ('EOF', None)]

Input: 2^3 + 4
Tokens: [('INTEGER', 2), ('POWER', '^'), ('INTEGER', 3), ('PLUS', '+'), ('INTEGER', 4), ('EOF', None)]

Input: 1.23 + 4.56

```

The lexer correctly identifies different tokens in the input expressions, handling integers, floats, operators, and parentheses. This forms the foundation for a calculator application and demonstrates the core principles of lexical analysis.
